## 1. 项目背景与目标

### 1.1 项目概述

本次开发任务聚焦于分销系统Web管理后台中代理管理模块的核心功能优化，特别是代理列表页面与代理详情页面之间的交互关系优化。项目旨在打造一个现代化、高度可定制且流畅的用户体验，使系统管理员、销售总监、团队领导和销售人员能够高效管理和查看代理信息。

### 1.2 需求分析

在深入理解项目架构和现有进度的基础上，我们确定了以下核心需求：

1. **列表-详情无缝导航**：实现从代理列表到详情页面的高级流畅导航，以及从详情页返回列表时保持原有状态
2. **数据一致性维护**：确保列表和详情页面之间的数据同步，避免数据不一致
3. **详情页增强功能**：优化代理详情页面，增加业绩趋势图表等数据可视化功能
4. **交互体验优化**：实现实时数据更新、响应式布局，提升整体用户体验
5. **权限控制优化**：基于角色的操作权限和数据访问控制

### 1.3 技术栈概览

本项目采用以下技术栈实现：

- **前端框架**：Vue 3 (Composition API、`<script setup>`)
- **UI组件**：shadcn-vue、Tailwind CSS
- **数据表格**：TanStack Table (Vue)
- **状态管理**：Pinia
- **路由管理**：Vue Router 4
- **HTTP客户端**：Axios（自定义拦截器）
- **数据模拟**：mockjs、axios-mock-adapter
- **图表可视化**：ECharts、vue-echarts
- **工具库**：dayjs（日期处理）
- **TypeScript**：类型安全保障

#### 2.1.2 高效缓存机制

为减少不必要的API请求，提升用户体验，我们实现了智能缓存系统：

```typescript
class AgentCache {
  private detailCache: Map<string, CacheItem<Agent>> = new Map();
  private performanceCache: Map<string, CacheItem<AgentPerformance>> = new Map();
  private readonly CACHE_TTL = 5 * 60 * 1000; // 缓存有效期：5分钟

  // 获取代理详情缓存
  getAgentDetail(id: string): Agent | null {
    const cachedItem = this.detailCache.get(id);
    if (cachedItem && cachedItem.expireAt > Date.now()) {
      console.log(`[Cache] 使用代理详情缓存: ${id}`);
      return cachedItem.data;
    }
    return null;
  }
  
  // 设置代理详情缓存
  setAgentDetail(id: string, data: Agent): void {
    console.log(`[Cache] 设置代理详情缓存: ${id}`);
    this.detailCache.set(id, {
      data,
      expireAt: Date.now() + this.CACHE_TTL
    });
  }
  
  // 获取代理业绩缓存，支持不同周期
  getAgentPerformance(id: string, period?: string): AgentPerformance | null {
    const cacheKey = `${id}-${period || 'default'}`;
    const cachedItem = this.performanceCache.get(cacheKey);
    if (cachedItem && cachedItem.expireAt > Date.now()) {
      console.log(`[Cache] 使用业绩数据缓存: ${cacheKey}`);
      return cachedItem.data;
    }
    return null;
  }
  
  // 设置代理业绩缓存
  setAgentPerformance(id: string, data: AgentPerformance, period?: string): void {
    const cacheKey = `${id}-${period || 'default'}`;
    console.log(`[Cache] 设置业绩数据缓存: ${cacheKey}`);
    this.performanceCache.set(cacheKey, {
      data,
      expireAt: Date.now() + this.CACHE_TTL
    });
  }
  
  // 清除指定代理的指定周期业绩缓存
  clearPerformanceCache(id: string, period?: string): void {
    const cacheKey = period ? `${id}-${period}` : id;
    this.performanceCache.delete(cacheKey);
    console.log(`[Cache] 清除代理业绩数据缓存: ${cacheKey}`);
  }
  
  // 清除指定代理的所有缓存
  clearAgentCache(id: string): void {
    // 清除详情缓存
    this.detailCache.delete(id);
    
    // 清除所有周期的业绩缓存
    const keysToDelete: string[] = [];
    this.performanceCache.forEach((_, key) => {
      if (key === id || key.startsWith(`${id}-`)) {
        keysToDelete.push(key);
      }
    });
    
    keysToDelete.forEach(key => this.performanceCache.delete(key));
    
    console.log(`[Cache] 清除代理所有缓存: ${id}, 共 ${keysToDelete.length + 1} 项`);
  }
}
```

该缓存系统具有以下特点：
- 设置了5分钟的缓存有效期，平衡性能与数据实时性
- 支持按周期（周、月、季度、年）缓存业绩数据
- 提供精细的缓存清除机制，支持清除特定周期或所有缓存
- 包含详细日志输出，便于调试和监控

### 2.2 列表-详情交互流程

#### 2.2.1 状态保持与同步机制

为实现列表与详情页面之间的无缝导航和状态保持，我们开发了`useListState` Composable：

```typescript
// src/composables/useListState.ts
export function useListState(store, router) {
  // 从URL同步状态到Store
  const syncStateFromURL = () => {
    const query = router.currentRoute.value.query;
    
    // 处理分页
    if (query.page) {
      store.listState.pagination.page = parseInt(query.page as string) || 1;
    }
    
    // 处理每页条数
    if (query.pageSize) {
      store.listState.pagination.pageSize = parseInt(query.pageSize as string) || 10;
    }
    
    // 处理筛选条件
    if (query.keyword) {
      store.listState.filters.keyword = query.keyword as string;
    }
    
    // 处理其他筛选条件
    // ...
  };
  
  // 从Store同步状态到URL
  const syncStateToURL = () => {
    const query: Record<string, string> = {};
    
    // 添加分页参数
    query.page = store.listState.pagination.page.toString();
    query.pageSize = store.listState.pagination.pageSize.toString();
    
    // 添加筛选条件
    if (store.listState.filters.keyword) {
      query.keyword = store.listState.filters.keyword;
    }
    
    // 添加其他筛选条件
    // ...
    
    // 更新URL，不触发路由变化
    router.replace({ 
      query: { ...router.currentRoute.value.query, ...query }
    });
  };
  
  // 导航到详情页
  const navigateToDetail = (id: string) => {
    // 保存当前列表状态到URL
    syncStateToURL();
    
    // 导航到详情页面
    router.push(`/agent/${id}`);
  };
  
  // 返回列表页，保持状态
  const navigateBackToList = () => {
    // 导航回列表页面，URL参数会保留之前的状态
    router.push('/agent/list');
  };
  
  // 自动同步URL状态
  onMounted(() => {
    if (router.currentRoute.value.path.includes('/agent/list')) {
      syncStateFromURL();
    }
  });
  
  // 监听路由变化
  watch(() => router.currentRoute.value.fullPath, () => {
    if (router.currentRoute.value.path.includes('/agent/list')) {
      syncStateFromURL();
    }
  });
  
  return {
    syncStateFromURL,
    syncStateToURL,
    navigateToDetail,
    navigateBackToList
  };
}
```

#### 2.3.3 生命周期与事件处理

为确保图表正常初始化和响应数据变化，我们实现了以下生命周期钩子和监听器：

```typescript
// 监听性能数据变化
watch(() => props.performanceData, (newVal) => {
  console.log("性能数据变化，触发图表更新:", newVal?.trendData ? true : false);
  nextTick(() => {
    if (chart.value) {
      updateChart();
    } else if (chartRef.value) {
      initChart();
    }
  });
}, { deep: true, immediate: true })

// 监听周期变化
watch(() => selectedPeriod.value, (newPeriod) => {
  console.log("周期变化为:", newPeriod);
  // 周期变化时无需重新初始化图表，只需更新
  nextTick(() => {
    if (chart.value) {
      updateChart();
    }
  });
})

// 监听DOM更新后，确保图表初始化和大小调整
onMounted(() => {
  // 使用nextTick确保DOM已更新
  nextTick(() => {
    // 延迟一点时间以确保DOM完全渲染
    setTimeout(() => {
      initChart();
      window.addEventListener('resize', handleResize);
    }, 100);
  });
})

// 当组件被卸载时，移除事件监听
onBeforeUnmount(() => {
  window.removeEventListener('resize', handleResize);
  if (chart.value) {
    chart.value.dispose();
    chart.value = null;
  }
})

// 处理窗口大小改变
const handleResize = () => {
  if (chart.value) {
    chart.value.resize();
  }
}

// 变更周期
const changePeriod = (period: string) => {
  selectedPeriod.value = period;
  emit('period-change', period);
}

// 刷新数据
const refreshData = () => {
  emit('refresh');
}
```

这些监听器和钩子函数确保了：

1. 组件能够正确响应数据变化
2. 在DOM准备就绪时初始化图表
3. 周期切换时正确更新图表
4. 窗口大小变化时调整图表尺寸
5. 组件卸载时清理资源

export function useListState(store, router) {
  // 从URL同步状态到Store
  const syncStateFromURL = () => {
    const query = router.currentRoute.value.query;
    
    // 处理分页、筛选条件等...
    if (query.page) {
      store.listState.pagination.page = parseInt(query.page as string) || 1;
    }
    
    // 其他状态同步...
  };
  
  // 从Store同步状态到URL
  const syncStateToURL = () => {
    const query: Record<string, string> = {};
    
    // 构建查询参数...
    query.page = store.listState.pagination.page.toString();
    
    // 更新URL，不触发路由变化
    router.replace({ 
      query: { ...router.currentRoute.value.query, ...query }
    });
  };
  
  // 导航到详情页
  const navigateToDetail = (id: string) => {
    // 保存当前列表状态到URL
    syncStateToURL();
    
    // 导航到详情页面
    router.push(`/agent/${id}`);
  };
  
  // 返回列表页，保持状态
  const navigateBackToList = () => {
    router.push('/agent/list');
  };
  
  // 自动同步URL状态
  onMounted(() => {
    if (router.currentRoute.value.path.includes('/agent/list')) {
      syncStateFromURL();
    }
  });
  
  // 监听路由变化
  watch(() => router.currentRoute.value.fullPath, () => {
    if (router.currentRoute.value.path.includes('/agent/list')) {
      syncStateFromURL();
    }
  });
  
  return {
    syncStateFromURL,
    syncStateToURL,
    navigateToDetail,
    navigateBackToList
  };
}

#### 6.4.2 IndexedDB存储
使用IndexedDB在本地存储重要数据，支持离线浏览和操作。

```typescript
// 设置IndexedDB
const dbPromise = idb.openDB('agent-management-db', 1, {
  upgrade(db) {
    db.createObjectStore('agents', { keyPath: 'id' });
    db.createObjectStore('performance', { keyPath: 'id' });
  },
});

// 存储数据
const storeAgent = async (agent) => {
  const db = await dbPromise;
  const tx = db.transaction('agents', 'readwrite');
  await tx.store.put(agent);
  await tx.done;
};

// 读取数据
const getAgent = async (id) => {
  const db = await dbPromise;
  return db.get('agents', id);
};
```
