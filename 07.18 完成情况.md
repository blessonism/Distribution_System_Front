📁 RBAC动态路由系统 (src/router/index.ts)
Vue Router的全局前置守卫是实现RBAC（基于角色的访问控制）的核心。它负责检查用户登录状态、获取权限并动态添加可访问的路由。
关键逻辑:
1. 白名单: to.meta?.requiresAuth为false的路由（如登录页）直接放行。
2. Token验证: 未登录用户访问受保护页面时，重定向到登录页。
3. 动态路由加载: 用户已登录但路由未加载时，根据用户角色从asyncRoutes中过滤出可访问的路由，并通过router.addRoute()动态注册。
4. 权限检查: 对于已加载的路由，进一步检查to.meta.roles确保用户有权访问。
// src/router/index.ts
// ... existing code ...
router.beforeEach(async (to, from, next) => {
  const userStore = useUserStore()

  // 1. 不需要登录的页面直接放行
  if (!to.meta?.requiresAuth) {
    next()
    return
  }

  // 2. 检查是否有token
  if (!userStore.token) {
    next('/login')
    return
  }

  try {
    // 3. 如果用户信息未加载且有token，先获取用户信息
    if (!userStore.userInfo && userStore.token) {
      await userStore.getUserInfo()
    }

    // 4. 确保动态路由已添加
    if (userStore.token && (!userStore.routesLoaded || !router.hasRoute('Layout'))) {
      const accessibleRoutes = filterRoutesByRole(asyncRoutes, userStore.roles || [])
      accessibleRoutes.forEach(route => {
        if (route.name && !router.hasRoute(route.name)) {
          router.addRoute(route)
        }
      })
      userStore.$patch({ routesLoaded: true })

      // 重新导航以确保路由信息正确
      next({ path: to.fullPath, replace: true })
      return
    }
    
    // 5. 通过所有检查，允许访问
    next()
  } catch (error) {
    // 发生错误，清除token并跳转登录
    userStore.logout()
    next('/login')
  }
})

📁 UserFormDialog.vue (用户表单)
负责新增和编辑用户，通过props.user是否存在来判断是创建模式还是编辑模式。
关键逻辑:
● watch props来初始化或重置表单数据。
● handleSubmit中根据props.user调用userApi.createUser或userApi.updateUser。
● 使用v-model:open控制弹窗显隐，并通过emit('success')通知父组件操作成功。
<!-- src/components/business/UserFormDialog.vue -->
<script setup lang="ts">
// ...
const handleSubmit = async () => {
  loading.value = true
  try {
    if (props.user) {
      // 编辑用户
      const updateData: UpdateUserRequest = { /* ... form data ... */ }
      await userApi.updateUser(props.user.id, updateData)
      toast({ title: '修改成功' })
    } else {
      // 创建用户
      const createData: CreateUserRequest = { /* ... form data ... */ }
      await userApi.createUser(createData)
      toast({ title: '创建成功' })
    }
    emit('success')
    emit('update:open', false)
  } catch (error: any) {
    toast({ title: '操作失败', variant: 'destructive' })
  } finally {
    loading.value = false
  }
}
</script>
